# Visão Geral

## Propósito

O projeto B3 é uma plataforma versionada para aquisição, preservação, normalização, validação e pesquisa de dados do mercado brasileiro.

## Escopo

Inclui, entre outros:

- séries históricas;
- COTAHIST;
- dados e documentos da B3;
- dados macroeconômicos;
- calendário de pregão e eventos;
- microestrutura e métricas de mercado;
- pipelines de ingestão;
- backtests;
- automação e auditoria.

## Princípio central

O projeto não trata um arquivo bruto como verdade simplesmente porque foi baixado. Cada conjunto de dados deve possuir contexto, origem, integridade e critérios de validação documentados.

## Marco 1986

1986 é o marco oficial para a reconstrução histórica. A liberação de cada novo período depende da reconciliação semântica e dos testes definidos para a etapa anterior.

## Resultado esperado

Construir uma base histórica e operacional que possa ser utilizada em pesquisa quantitativa, estudos de microestrutura, backtesting e futuras integrações de automação.
