# 03 — MACRO

## Objetivo
Relacionar eventos macroeconómicos com ativos da B3 sem confundir correlação com causalidade.

## Módulos
- `CALENDARIO/`: horário, timezone, fonte, consenso, divulgado, revisão e surpresa.
- `INDICADORES/`: séries oficiais com unidade, frequência, metodologia e data de publicação.

Priorizar BCB, IBGE, Tesouro Nacional e, para eventos externos relevantes, as entidades oficiais correspondentes. Guardar vintages/revisões quando disponíveis; os dados conhecidos hoje podem diferir dos disponíveis no momento histórico da decisão.
