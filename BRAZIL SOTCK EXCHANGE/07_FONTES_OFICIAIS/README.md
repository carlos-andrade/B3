# 07 — FONTES OFICIAIS

Manter catálogo de fontes oficiais, endpoints/páginas, datasets, frequência, formato, licença, restrições, última verificação e responsável pela revisão. Priorizar B3, CVM, Banco Central do Brasil, IBGE e Tesouro Nacional. Registar alterações de URL, layouts e normativos; nunca inferir autorização de redistribuição apenas porque os dados são acessíveis publicamente.
