# RAW — Dados originais

Guardar aqui apenas artefactos de origem preservados sem alteração, se as licenças permitirem a sua inclusão no repositório. Para ficheiros grandes ou sujeitos a restrições, guardar o artefacto no armazenamento autorizado e versionar apenas manifesto, metadados e hash.

Cada lote deve registar fonte, URL, data de obtenção UTC, data de mercado, timezone, tamanho, SHA-256, licença e identificador da execução. Nunca sobrescrever silenciosamente um ficheiro original.
