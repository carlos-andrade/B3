# ICP — Ideal Customer Profile

## ICP-01 — Trader avançado
### Problema
Dados existem, mas estão dispersos entre plataformas, relatórios e fontes.

### Necessidade
Contexto operacional consolidado para acompanhar mercado, volume, volatilidade, níveis e eventos.

### Produto inicial
Radar B3.

### Evidência necessária
- entrevistas;
- taxa de ativação;
- uso recorrente;
- conversão para pagamento;
- churn;
- disposição a pagar.

## ICP-02 — Pequena mesa / profissional
### Problema
Necessidade de transformar dados em sinais, relatórios e acompanhamento sistemático sem construir toda a infraestrutura internamente.

### Produto
Pro Fluxo / B2B Analytics.

## ICP-03 — Quant / pesquisador
### Problema
Necessidade de dados tratados, histórico, metodologia reproduzível e backtests.

### Produto
B3 Quant Lab.

## ICP-04 — Fintech / empresa de tecnologia financeira
### Problema
Necessidade de indicadores, APIs, alertas e componentes de inteligência de mercado.

### Produto
API / White-label / Enterprise.

## Regra de validação

ICP não será considerado validado por opinião. A validação mínima exige evidência de comportamento:
- uso;
- retorno;
- pagamento;
- retenção;
- indicação;
- expansão.

## Critério de avanço

Um segmento só deve receber investimento relevante depois de demonstrar combinação aceitável de:
dor real + acesso ao comprador + disposição a pagar + retenção + viabilidade de dados/licenciamento.

Status: hipótese de ICP.
