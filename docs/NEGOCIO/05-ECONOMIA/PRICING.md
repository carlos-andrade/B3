## Princípio

Preço deve ser testado contra valor percebido, custo de servir, risco e disposição a pagar. Os preços abaixo são pontos de partida para experimentação.

| Camada | Faixa inicial de teste | Modelo |
|---|---:|---|
| Radar B3 | R$79–199/mês | Assinatura |
| Pro Fluxo | R$249–599/mês | Assinatura |
| B3 Quant Lab | R$299–1.500/mês | Assinatura |
| B2B Analytics | R$2.000–10.000+/mês | Contrato |
| API / White-label | Sob proposta | Contrato + uso |
| Engenharia | R$5.000–50.000+ | Projeto |

## Experimentos

Testar:
1. preço mensal;
2. preço anual;
3. plano com limite de uso;
4. plano profissional;
5. plano empresarial;
6. cobrança por API/volume quando aplicável.

## Métricas

Para cada experimento registrar:
- visitantes;
- leads;
- trial;
- conversão;
- receita;
- churn;
- expansão;
- suporte;
- custo variável;
- margem de contribuição.

## Regra

Não escolher preço apenas por concorrência. O preço deve ser validado por comportamento real do comprador.
