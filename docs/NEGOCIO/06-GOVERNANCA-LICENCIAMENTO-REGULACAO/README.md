# Governança, Licenciamento e Regulação

## Regras
1. Separar dado bruto, dado licenciado, dado derivado e análise própria.
2. Validar direitos de redistribuição antes de qualquer produto comercial.
3. Avaliar enquadramento regulatório de cada produto antes do lançamento.
4. Não confundir educação, analytics e ferramentas com recomendação individualizada.
5. Manter evidências, fontes, versões e decisões auditáveis.

## Status
Esta pasta é obrigatória para qualquer produto comercial derivado do projeto B3.
