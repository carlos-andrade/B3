A política demonstra que licenciamento e consumo de Market Data são componentes econômicos do produto.

Cada produto deve ser modelado por: Produto → Dataset → Depth → Timeliness → Display/Non-Display → Finalidade → License → Counting Unit → Custo → Margem.

Radar B3: classificar os dados exibidos e a licença aplicável.

Pro Fluxo: indicadores derivados como agressão, fluxo e Cumulative Delta exigem análise da origem, transformação e permissões.

B3 Quant Lab: classificar históricos, backtests, datasets tratados e derivados.

API / White-label: não presumir que um indicador derivado pode ser redistribuído sem autorização.

B2B Analytics: avaliar o enquadramento de cada cliente quando houver display, non-display, distribuição, localização ou múltiplos usuários.

Regra: nenhuma classificação comercial deve ser inferida apenas por analogia. Deve haver fonte, regra de suporte, interpretação operacional, responsável, data e versão da política.
