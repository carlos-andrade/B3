# Cenários de Receita

## Cenário ilustrativo
### B2C
300 clientes × R$199 = R$59.700/mês.

### B2B
10 clientes × R$3.000 = R$30.000/mês.

### Projetos
2 projetos × R$10.000 = R$20.000/mês.

### Total hipotético
R$109.700/mês = R$1.316.400/ano.

## Observação
