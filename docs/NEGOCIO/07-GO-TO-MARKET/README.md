# Go-to-Market

## Etapas
1. Definir ICP.
2. Identificar dor mensurável.
3. Construir MVP estreito.
4. Testar disposição a pagar.
5. Medir conversão e retenção.
6. Ajustar preço e proposta de valor.
7. Escalar aquisição somente após evidência de product-market fit.

## Princípio
Não começar tentando construir um "Bloomberg brasileiro". Começar por um problema operacional específico e mensurável.
