# Mercados-alvo

## Segmentos
- Traders pessoa física
- Traders avançados e pequenas mesas
- Quants e pesquisadores
- Gestores e consultores
- Fintechs
- Empresas de tecnologia financeira

## Princípio
Cada segmento terá ICP, dor, solução, ticket, canal de aquisição, risco regulatório e evidência de disposição a pagar documentados antes de escalar.
