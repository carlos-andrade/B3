## Objetivo

Contratos futuros padronizados: índices, juros, moedas, commodities, ações/ETFs e demais contratos vigentes.

## Regras de integridade

- Não presumir que um instrumento esteja ativo, listado ou negociável sem confirmação em fonte oficial para a data de referência.
- Preservar a origem e a data de captura de cada registo.
- Separar factos oficiais, classificações derivadas e hipóteses; não usar este README como recomendação de investimento.
